项目名称：基于大语言模型的校园二手教材智能交易平台

一、项目背景
高校教材每学期更换，学生手中大量教材闲置，而新学期又要花钱买新书。据统计，一名本科生四年教材支出约 2000 元，其中约 60% 的教材在学期结束后就不再使用。目前校园内的二手交易主要依靠 QQ 群、微信群和闲鱼，信息分散、匹配效率低、交易缺乏信任保障。

二、项目目标
搭建一个面向本校学生的二手教材交易平台，利用大语言模型实现教材信息的自动结构化、智能匹配推荐和交易沟通辅助，降低学生找书、卖书的成本。

三、技术方案
1. 后端采用 Python FastAPI 框架，前端采用 Vue3 + Element Plus。
2. 数据存储使用 MySQL 存储用户和商品数据，使用 Redis 做会话缓存。
3. 核心功能引入大语言模型：
   （1）卖家只需上传教材封面照片，系统调用多模态大模型自动识别书名、作者、出版社、版次，生成结构化商品信息，卖家无需手动填写。
   （2）基于大语言模型对买卖双方的教材需求做语义匹配，相比关键词匹配能显著提升匹配准确率。
   （3）接入大语言模型作为交易助手，自动回答买家关于教材成色、交易地点的问题。
4. 平台采用微信小程序 + Web 双端，预计服务本校 5000 名学生。

四、进度安排
第 1-2 周：需求分析与数据库设计
第 3-5 周：后端接口开发
第 6-8 周：大模型功能接入与联调
第 9-10 周：前端开发与测试上线

五、预期成果
完成平台开发并上线试运行，形成一份毕业论文和一套软件著作权材料。

六、团队
本项目由 3 名本科生完成，分别负责后端、前端和算法。
